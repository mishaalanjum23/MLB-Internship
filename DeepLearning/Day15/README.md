# Document Image Enhancement Tool

## Transformations Implemented

- **Perspective Transformation:** Used to straighten tilted document images.
- **Grayscale:** Converted the document to black and white to make processing easier.

## Enhancement Techniques

- **Gaussian Blur:** Reduced image noise.
- **Brightness & Contrast Adjustment:** Made the document clearer and easier to read.
- **Image Sharpening:** Improved the sharpness of the text.

## Biggest Impact on Document Quality

The **image sharpening** had the biggest impact because it made the text look clearer and easier to read.

## Challenges Faced

The main challenge was applying the perspective transformation. It required selecting the document corners manually, and the same points did not work for every image.
