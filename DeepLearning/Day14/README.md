##  OpenCV

## BGR vs RGB

RGB stands for **Red, Green, Blue** and is the color format used by most image libraries. OpenCV uses **BGR (Blue, Green, Red)** instead, so the order of the color channels is different.

## What are Grayscale Images?

A grayscale image has only one channel that stores brightness values instead of colors. They are useful because they reduce image complexity and are often used as a preprocessing step in computer vision tasks.

## OpenCV Functions Used

* cv2.imread() – Read an image
* cv2.imwrite() – Save an image
* cv2.cvtColor() – Convert image to grayscale
* cv2.resize() – Resize an image
* cv2.rotate() – Rotate an image
* cv2.flip() – Flip an image
* cv2.rectangle() – Draw a rectangle
* cv2.circle() – Draw a circle
* cv2.line() – Draw a line
* cv2.polylines() – Draw a polygon
* cv2.putText() – Add text to an image
