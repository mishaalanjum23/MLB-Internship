# Real-Time Video Processing Tool

## How OpenCV Reads Videos

OpenCV reads a video using `cv2.VideoCapture()`. A video is made up of many images called frames. OpenCV reads one frame at a time, processes it, and displays or saves the result until the video ends.

## What FPS Means

FPS (Frames Per Second) is the number of frames displayed in one second. A higher FPS makes the video appear smoother.

## Processing Techniques Used

* Converted each frame to grayscale.
* Applied Gaussian Blur to reduce noise.
* Applied Canny Edge Detection to detect object edges.
* Displayed both the original and processed video.
* Saved the processed video as a new file.
