## What is Deep Learning?

Deep Learning is a branch of Machine Learning that uses artificial neural networks with multiple layers to learn patterns from data. It is commonly used for tasks like image recognition, speech recognition etc.

## Machine Learning vs Deep Learning

* **Machine Learning** usually requires manual feature selection and works well on smaller datasets.
* **Deep Learning** automatically learns features from data using neural networks and performs better on large and complex datasets.

## What is a Perceptron?

A perceptron is the basic building block of a neural network. It takes input values, multiplies them by weights, adds a bias, applies an activation function, and produces an output.

## Activation Functions Explored

* **ReLU:** Commonly used in hidden layers because it is fast and simple.
* **Sigmoid:** Mostly used in output layer for binary classification.
* **Tanh:** Used in hidden layers when outputs between -1 and 1 are preferred.
* **Softmax:** Used in the output layer for multi-class classification.
