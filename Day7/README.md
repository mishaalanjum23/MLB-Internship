## What is Classification?

Classification is a machine learning task where the model predicts a category or class, like **Yes/No** or **Spam/Not Spam**.

## Difference between Regression and Classification

* **Regression** predicts numerical values (e.g., house price or marks).
* **Classification** predicts class or labels (e.g., flower species or Pass/Fail).

## Evaluation Metrics Used

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

## Model Performance and Observations

The Logistic Regression model performed very well on the Iris dataset. It achieved very high accuracy, and the confusion matrix showed that the predictions were correct for all test samples. Overall, the model worked well for this dataset.
