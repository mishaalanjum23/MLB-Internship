# Iris Flower Clustering & Visualization

## What is Clustering?

Clustering is an unsupervised learning technique that groups similar data points together. It finds patterns in the data without using labels.

## What is PCA?

PCA is a dimensionality reduction technique. It reduces the number of features while keeping most of the important information, making the data easier to visualize.

## How did you determine the best value of K?

I used the Elbow Method by plotting the inertia values for different K values. The graph showed an elbow around **K = 3**, so I selected 3 as the optimal number of clusters.

## What insights did you gain from the visualizations?

The K-Means plot showed that the data was grouped into three clusters. The PCA plot reduced the data to two dimensions, making it much easier to visualize and understand the distribution of the clusters.
